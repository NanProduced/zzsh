# 会员与礼遇视觉物料

共26份独立物料，每份提供PNG与WebP。PNG为透明边缘/纹理备用源，页面优先使用WebP。另保留6组根路径卡面兼容别名，指向A系列，不代表业务或用户选择默认等级。

| 类型 | 路径（相对本目录） | 尺寸 |
|---|---|---|
| A 细纹金属横卡 | `a-metal/<tier>-card.png` / `.webp` | 1020×600 |
| B 哑光陶瓷方卡 | `b-ceramic-square/<tier>-card.png` / `.webp` | 768×768 |
| C 切面金属横卡 | `c-faceted/<tier>-card.png` / `.webp` | 1020×600 |
| 六档身份区背景 | `<tier>-header.png` / `.webp` | 1920×640 |
| 挚友礼遇（C） | `friend-badge.png` / `.webp` | 512×512，透明 |
| 尊享礼遇（C） | `prestige-badge.png` / `.webp` | 512×512，透明 |
| 旧接入约定兼容路径 | `<tier>-card.png` / `.webp` | 与A对应图片字节一致 |

`<tier>`：普通 `standard`、银卡 `silver`、金卡 `gold`、铂金 `platinum`、钻石 `diamond`、黑金 `black-gold`。

## 接入

- 公开URL前缀为 `/art/membership/`。可以按场景显式选A或C横卡；B方卡用于方形槽位，不能拉伸成横卡。根路径卡面只是原M1文件约定的A兼容副本。
- 卡面使用 `object-fit: contain`，保留比例和全部边缘。图像外部及圆角为透明，样式层可按场景添加阴影。
- 背景为3:1无文字底图，使用 `background-size: cover`。左侧为文字区，右侧有材质细节。普通至铂金建议使用深色文字；钻石和黑金使用浅色文字，与全页深浅主题分别处理。
- 礼遇标识为独立透明图形，建议24–48px显示；挚友为双向开口，尊享为四向星芒。不把礼遇图标作为成长等级，也不由素材判断授予状态。
- 姓名、积分、有效期、金额、可操作状态由实际API读取并用DOM呈现。未知等级使用中性状态，不默认取普通卡。只有黑金卡包含终身标识。
- 如果邻近DOM已经显示等级/礼遇名称，装饰图片使用空alt；独立呈现时提供对应中文alt。图片失败不能使用户身份和业务信息不可读。
- `manifest.json`列出尺寸、透明信息、PNG/WebP路径、体积与SHA256。当前文件仅是视觉物料，应用接入后的主题、响应式与键盘行为由页面验证负责。
