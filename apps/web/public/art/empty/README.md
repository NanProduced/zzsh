## 接入

- 公开 URL 前缀为 `/art/empty/`。页面优先使用 WebP，PNG 为透明备用源，两者均含 alpha（WebP 为 `yuva420p`，PNG 为 `rgba`）。
- 显示框：订单列表桌面 240×180、手机 160×120；总览「我的租入／我的出租」摘要用紧凑档 132×99。`object-fit: contain` 保持比例与全部透明边缘，不放大成主视觉海报。
- 图片仅装饰：`alt` 为空，标题、说明与动作由 DOM 表达。图片加载失败时文字与入口仍成立，脚本隐藏破图占位。
- 只在身份已确认、请求成功、数据已知且确实为空时展示。筛选无结果、指定账号无订单、加载中、读取失败、权限异常、状态未知一律不用人物插图。
- 有插图的总空态隐藏列头、空页脚线与重复模块标题，不为维持网格保留大面积空白。
