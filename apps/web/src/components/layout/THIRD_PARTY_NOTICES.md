# Header / Footer 第三方来源

Header 的滚动状态监听和弹簧参数适配自 [Aceternity Resizable Navbar](https://ui.aceternity.com/components/resizable-navbar)，2026-09-13 从 [官方 registry](https://ui.aceternity.com/registry/resizable-navbar.json) 核对。改为搜索优先、稳定占位、同一输入框、触屏/窄屏静态吸顶及减少动态适配；图标与菜单复用项目 Lucide / Radix，不复制演示品牌或整套抽象组件。

Aceternity 使用[独立站点许可](https://ui.aceternity.com/licence)，允许修改并用于终端产品，不允许将源码独立再分发或作为模板出售。不能将这一来源统称为 MIT。

Footer 结构和进入视口的轻微位移动画适配自 [SmoothUI footer-1](https://smoothui.dev/docs/blocks/footer)，2026-09-13 核对[官方 registry](https://smoothui.dev/r/footer-1.json)。保留品牌两列、链接三列和版权区，改为真实中文业务链接，移除演示社交账号，主题使用洲洲 tokens；初始内容始终可见。以下为上游 [LICENSE](https://github.com/educlopez/smoothui/blob/main/LICENSE) 原文。
