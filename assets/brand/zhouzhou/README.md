- 品牌名称：**洲洲商行**。
- 中文slogan：**玩得更远，一直有洲洲**。分两行时仍使用“得”，不得回退为“的”。
- 正式Logo使用上级目录原始品牌文件；不得从设计稿截取失真Logo或让模型重新绘制标识。

## 形象一致性

按形象设定图保持黄色头部、橙红眼睛、白色头箍、黑金耳机与麦克风、黑色战术服、手套和靴子的组合，以及大头小身比例。以友好、专注、可靠的游戏伙伴呈现；不另造人物来代替，不做恐怖/血腥化处理。

动作或表情可变化，核心轮廓、眼睛、耳机、服装与配色需保持可辨认。同一次生成传入形象设定及相关动作/表情参考；如稿件局部细节不一致，以形象设定为基础，不凭图片噪声新增设定。

稿内色板作为IP素材参考：品牌黄#FFD64D、瞳孔红#C84228、战术黑#1A1A1A、科技灰#A7A7A7、头箍白#F2F2F2、金属金#D4AF6B。它们不自动覆盖现有全站主题变量或代表所有文字对比度合格。

## 生成与使用

1. 优先生成独立角色/背景，Logo、slogan、业务文案及按钮使用真实资源与UI叠加；衣服、耳机上的标识也要复核，不能把生成近似当正式Logo。
2. 新物料不得覆盖这四份源稿。按用途另存衍生稿；网页交付再制作适合尺寸、透明背景、明暗背景边缘和压缩格式的版本。
3. 深浅主题保持角色身份与主色，不反转角色颜色；调整的是背景、光照、边缘明暗和UI对比。
4. 示例中VIP、优惠、第三方登录、7×24服务、保障承诺等不构成功能或运营授权。只为已实现且已确认的业务制作对外宣传。
5. IP用于平台品牌、引导和帮助；不得冒充用户头像、真实客服在线状态、审核通过或交易成功。商品截图、装备皮肤凭证和游戏角色仍须真实对应。
6. 不同业务语义不得复用同一插画或宣传物料；只有语义本就相同的用途才可复用。CTA协助与成交播报必须使用独立动作素材。
7. 不把整张图鉴缩小后塞入页面，不给每个按钮重复加角色。先确定一个画面的主次，再选择动作。

当前仅归档与确认参考规范；未生成独立角色切图、未替换业务UI、未验证各终端物料。
