## 使用规则

- 直接复用 Owner 图形，不再用临时盾牌、字母或自创图案代替正式 Logo。
- 按背景对比度选择合适物料；透明深色图在深色背景上可能不可见，实施前需在明暗背景预览。
- 保持比例、完整轮廓及留白，不拉伸、不擅自重绘或增加发光/渐变。
- 根据实际页面选择方形或横向版；各变体具体用途未逐一冻结，不凭文件编号推断主次。
- 管理端与用户端从此目录按需引用或在构建时分发，不另建品牌包或复制整套物料。
- 当前没有 SVG、专用 favicon 或字号适配衍生物；实际需要时再制作，不把 PNG 改扩展名伪装成矢量。
