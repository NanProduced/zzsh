# 账号公开查看、可租状态与编号

公开查看、供给当前可租、该租客本次可交易分别核定。客户端状态或收藏不能替代个人确认和建单时的锁内校验。

## 入口

| 入口 | 范围 |
| --- | --- |
| `GET /api/v1/supply/listings` | 默认仅当前原生有效发布、空闲并通过供给前置的可租账号；标题/模糊编号筛选不越过这个候选池 |
| `GET /api/v1/supply/listings/lookup?number=&gameId=` | 完整文本编号精确查找；gameId可选。可以返回仍获准公开的已租/待付款占用资料 |
| `GET /api/v1/supply/listings/{accountId}` | 稳定ID公开详情，与精确查找、收藏共用公开投影 |
| `GET /api/v1/supply/me/favorites` | 本人收藏关系；可查看的暂不可租账号仍有编号、状态和详情入口；失去公开资格则通用不可用且listing=null |

精确查找参数只允许number/gameId，重复参数、q/cursor等混用拒绝400；用户公开查询接受日期有效、流水非零的`ZZYYYYMMDDSSSSSS`新平台编号，兼容既有已发`AC`加至少10位数字的canonical号。格式相符不构成授权，仍须命中已持久分配编号及公开守卫；旧号和内部ID拒绝400，全程保留字符串。多个目标无法唯一定位时通用409，不返回候选身份或私因；唯一目标不满足公开条件或没有目标时404。该路由优先于通用`{accountId}`分支。

Next `/api/supply/...`和API用户BFF `/api/bff/user/supply/...`只适配路径、用户Cookie和公开链接，保留状态/no-store，不直连数据库或另算资格。

## 原生公开版本与状态

号主主动下架后，该出租记录进入不可恢复终态，退出公开与新租；需再次出租时重新填写表单创建新账号记录。未发布草稿和审核退回的资料仍可修改；已发布的资料不可在同一账号上新建修改版本。订单读取保留原账号和冻结资料，不以当前公开性推断订单是否结算。

同一账号保留稳定ID和取消历史，同时最多一条待付款或已付款的活跃订单。未付款取消或超时只释放本次占用，不自动改变运营限制或其他发布条件。租用经正常或提前结算生效后，在原过账事务内将账号归档，不允许再次核价、发布或成交；原订单、资料与取消历史保留。既有原生完单即使账号仍为ACTIVE，也由完成事实阻止复用；迁入历史完单不直接替代当前账号终态。

管理端`queryVersion=3`以`businessState`返回LISTED（上架中）、IN_PROGRESS（订单进行中）、OFFLINE（已下架或运营限制）、COMPLETED（完成租用）；依据不足返回null。OFFLINE 不单独证明终态，须结合账号生命周期；未上架草稿不冒充下架。`status`筛选绑定分页游标，不能把前端显示状态作为操作授权。账号独立详情统一使用`/supply/reviews/:id`，旧`/supply/accounts/:id`保留兼容；仅有账号读取权限时裁去审核、内部归因、私有图片及处置信息，列表和写操作权限不随之扩展。

管理账号列表和详情的`baseRenterHaffRatioWanPerYuan`来自同一资料版、游戏、规则及内容摘要校验后的租客基础比例，单位为万哈夫币/元，缺依据为null；不从舍入后的金额反算，也不代表会员个人净价。游标分页有可靠总数时显示总页数；需要逐条核对的筛选无法完整计数时保留未知，并按顺序翻页。

公开资料继续核号主活性/实名/成年、游戏服务、账号生命周期/运营限制、合法公开版本与内容哈希、该版本的规则接受事实。主动下架、归档、封禁或未获准公开的资料保持隐藏。当前没有独立“隐私撤回公开”写入口；未来隐私撤回必须有独立、权威的拒绝事实。

当前仍安全可公开的媒体按账号/号主/游戏、冻结byteHash、用途、技术和公开资格逐件投影；缺失或撤权素材不出URL，非媒体资料可以如实无图。发布和新租的原媒体门禁不因缺图被放宽。资料和媒体在REPEATABLE READ READ ONLY同一快照中读取，响应no-store；撤权后开始的新快照拒绝，已开始的旧快照可以一致地结束。

草稿绑定只接受当前账号、号主和游戏的 USER_SUPPLY 展示图或私有凭证，保存不要求已审核或已封存报价；非法绑定在任何替换前统一拒绝400。发布、批准和新租重新核对归属及完整封存素材集合；私有凭证同样不能跨属。数据库现有归属触发器保持不变。历史只读详情逐件隐藏不匹配图片，保留无图资料，不能因缺图伪造可租状态。

公共DTO增加`availability.state`和`canCreateOrder`：

| state | 解释 |
| --- | --- |
| RENTABLE | 供给前置通过；canCreateOrder=true仍不代表已通过该租客会员/身份或最终付款资格 |
| PENDING_PAYMENT / RENTED | 权威原生订单分别为待付占用/已付占用；不输出第三方订单ID、租客、押金或到期资料 |
| OCCUPIED | 已确认占用但无法安全细分，显示暂不可租 |
| OFFLINE | 未终止记录但暂不接单；具体公开与操作权限仍由服务端核定 |
| UNKNOWN / UNAVAILABLE | 资格未核定或其他供给前置未通过；不默认FREE或已租 |

非RENTABLE均canCreateOrder=false，详情不装配租赁确认。其金额仅是已公开版本的资源费用参考，不是本人最终报价。Owner内价、利润、资金责任和当前第三方订单金额不进入公共投影。真正读取异常保持失败，不伪装成成功空结果。

## 历史只读与逐件准入

旧三角洲账号无论来源状态如何，均不再经公开目录、公开详情或公开媒体入口展示；历史订单及本人账号资料按各自授权读取。其他游戏的历史详情仍须符合其来源准入和业务范围。冻结来源状态/时间不能当作今天的占用状态。

原有NONE且无display overlay基线，与受审cap的NONE/UNRESOLVED分支分列，其他身份/风险/隐私守卫保持。非三角洲来源若有明确业务准入，v3文件仍须逐件绑定来源状态与全部来源/摘要/公开字段；许可不覆盖旧三角洲账号的退役规则。可保存状态不等于已公开。

## 账号编号

稳定accountId继续作为主键/FK/详情路由，不用用户ID、订单号或截断UUID伪造展示编号。新发号为`ZZ`＋发号时数据库`Asia/Shanghai`日期`YYYYMMDD`＋六位当日流水`000001..999999`；每天使用独立日期计数行、原子分配，达到上限拒绝，不循环或截断。日期不取来源cutoff、客户端时钟或事务开始时的旧日期。原生新建仍在现有幂等事务内发号；编号与计数同事务回滚，成功回执重放不重新发号。账号虽也以ZZ开头，仍与订单/管理员编号资源完全独立。既有已发AC及合法ZZ保留，不能覆盖。

旧三角洲账号保留来源映射和已有历史标识，发号或读取均不提升其公开或可租资格；其他旧来源只按各自已核准范围处理。原生新建既定同事务发号保持。新分配只调用日期编号能力；缺新表/新函数时拒绝，不先消费旧AC序列。绝不将旧resourceNo固化为新号；既有非空且不符合已发AC/合法ZZ格式的值须停下核查，不能清号重发。

旧号alias只供管理及内部承接解析，复用不可变legacy read snapshot与精确来源map并保留前导零。内部解析先在可选游戏范围内核唯一目标，不能靠另一目标当前不可见消除重号；重复旧号不决定或阻止独立新号分配。用户公开lookup不读取该alias，稳定ID详情和既有收藏继续受同一公开守卫保护。无需复制可变alias表。

编号迁移须先核既有非空格式和重复，再装配日期计数能力并保留唯一/不可变约束；既有ZZ仅用于初始化对应日期高水位。runtime仅获新无参数函数EXECUTE，不可直接写计数表，不使用旧AC生成函数或旧账号序列权限。旧NULL和冲突分类、回填量由实际有界事实决定；prepareAccountNumberBackfill只准备、writeAllowed=false。真实回填另按维护授权执行，函数始终使用调用方同一事务client；旧snapshot/cap/来源摘要不改。

接口返回nullable编号时，Web诚实显示未提供，不用内部ID或标题数字补号。不可用收藏只保留本人关系及取消能力，不返回旧标题、编号、价格或私有原因。

用户自己的供给及旧单也只展示canonical新号。旧单的金额、付款、退款责任和终态独立保留；账号资料不可读时，标题使用未提供状态、账号ID/编号为空，不泄露当前私有标题或旧号，也不把订单已完成解释成账号资料已完整。
