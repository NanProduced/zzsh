# 账号公开查看、可租状态与编号

公开查看、供给当前可租、该租客本次可交易分别核定。客户端状态或收藏不能替代个人确认和建单时的锁内校验。

## 入口

| 入口 | 范围 |
| --- | --- |
| `GET /api/v1/supply/listings` | 默认仅当前原生有效发布、空闲并通过供给前置的可租账号；标题/模糊编号筛选不越过这个候选池 |
| `GET /api/v1/supply/listings/lookup?number=&gameId=` | 完整文本编号精确查找；gameId可选。可以返回仍获准公开的已租/待付款占用/普通下架资料 |
| `GET /api/v1/supply/listings/{accountId}` | 稳定ID公开详情，与精确查找、收藏共用公开投影 |
| `GET /api/v1/supply/me/favorites` | 本人收藏关系；可查看的暂不可租账号仍有编号、状态和详情入口；失去公开资格则通用不可用且listing=null |

精确查找参数只允许number/gameId，重复参数、q/cursor等混用拒绝400；编号保留文本、大小写和前导零，不作数字转换。多个源绑定目标无法唯一定位时通用409，不返回候选身份或私因；唯一目标不满足公开条件或没有目标时404。该路由优先于通用`{accountId}`分支。

Next `/api/supply/...`和API用户BFF `/api/bff/user/supply/...`只适配路径、用户Cookie和公开链接，保留状态/no-store，不直连数据库或另算资格。

## 原生公开版本与状态

普通下架使用owner_paused，停止新租但保留获准公开的详情。当前版本是未公开草稿时，只能选择最后一个有真实publication元组的有效公开版本，明确返回其versionId/hash绑定；不展示新草稿。原生已接管的账号不回退旧legacy快照。

公开资料继续核号主活性/实名/成年、游戏服务、账号生命周期/运营限制、合法公开版本与内容哈希、该版本的规则接受事实。归档、封禁或未获准公开的资料保持隐藏。当前没有独立“隐私撤回公开”写入口；不能把普通下架伪装成该操作。未来隐私撤回必须有独立、权威的拒绝事实，现有运营限制/归档/主体拒绝边界仍生效。

当前仍安全可公开的媒体按账号/号主/游戏、冻结byteHash、用途、技术和公开资格逐件投影；缺失或撤权素材不出URL，非媒体资料可以如实无图。发布和新租的原媒体门禁不因缺图被放宽。资料和媒体在REPEATABLE READ READ ONLY同一快照中读取，响应no-store；撤权后开始的新快照拒绝，已开始的旧快照可以一致地结束。

公共DTO增加`availability.state`和`canCreateOrder`：

| state | 解释 |
| --- | --- |
| RENTABLE | 供给前置通过；canCreateOrder=true仍不代表已通过该租客会员/身份或最终付款资格 |
| PENDING_PAYMENT / RENTED | 权威原生订单分别为待付占用/已付占用；不输出第三方订单ID、租客、押金或到期资料 |
| OCCUPIED | 已确认占用但无法安全细分，显示暂不可租 |
| OFFLINE | 普通下架或已不是当前接单版本；详情可查看、不可建单 |
| UNKNOWN / UNAVAILABLE | 资格未核定或其他供给前置未通过；不默认FREE或已租 |

非RENTABLE均canCreateOrder=false，详情不装配租赁确认。其金额仅是已公开版本的资源费用参考，不是本人最终报价。Owner内价、利润、资金责任和当前第三方订单金额不进入公共投影。真正读取异常保持失败，不伪装成成功空结果。

## 历史只读与逐件准入

LEGACY_READ_ONLY不进入默认可租列表，可在原许可范围通过精确编号、详情或收藏查看，仍`quote=null / canCreateOrder=false / historicalQuote`。冻结来源状态/时间放在`sourceAvailability`，不能当作今天的占用状态。

原有NONE且无display overlay基线，与受审cap的NONE/UNRESOLVED分支分列，其他身份/风险/隐私守卫保持。原v1/v2许可只容许source_status=3。v3文件须逐件额外绑定sourceStatus及全部原来源/版本/摘要/公开字段，才允许来源4/5/6的详情、精确查找和收藏；可保存状态不等于已公开。该能力仍受文件SHA和实际运行资源绑定，不因协议支持而自动产生任何新增准入。

## 账号编号

稳定accountId继续作为主键/FK/详情路由，不用用户ID、订单号或截断UUID伪造展示编号。原生新建在现有幂等事务内持久分配独立账号序列的AC公开号（至少10位数字，不截断增长宽度）；不占用订单ZZ或管理员登录号序列。既有非空号保留，不能静默覆盖。

旧号alias复用不可变legacy read snapshot与精确来源map，保留前导零；原生接管优先保留可信旧号，同号多目标或缺映射明确冲突，不猜目标。查询先在可选游戏范围内核唯一目标，不能靠“另一目标当前不可见”消除重号；唯一目标仍必须过资料公开守卫。无需复制可变alias表。

编号迁移须先核既有非空格式和重复，再装配唯一/不可变约束及账号序列权限。旧NULL和冲突分类、回填量由实际有界事实决定；prepareAccountNumberBackfill只准备、writeAllowed=false。真实回填另按维护授权执行，函数始终使用调用方同一事务client；旧snapshot/cap/来源摘要不改。

接口返回nullable编号时，Web诚实显示未提供，不用内部ID或标题数字补号。不可用收藏只保留本人关系及取消能力，不返回旧标题、编号、价格或私有原因。
